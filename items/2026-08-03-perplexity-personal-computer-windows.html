Personal Computer arrive sur Windows — agent desktop à 200 $/mois, orchestration de 20+ modèles, contexte local qui transite par le cloud

Extrait du brief MCP passe stateless, les labos avouent leurs évasions — 2026-08-03

Contexte étendu

Personal Computer, lancé sur macOS en avril et passé en disponibilité générale en mai, arrive sur Windows le 28 juillet. La cible est explicite : le parc de ~1,4 milliard de postes où Microsoft pousse Copilot. Le produit reste réservé aux plans Max et Enterprise Max, soit un plancher de 200 $/mois par siège — le palier Pro à 20 $/mois n'y donne pas accès, et le reste des utilisateurs passe par une liste d'attente.

Fonctionnellement, l'agent pilote les fichiers locaux et les applications natives Windows — Excel, PowerPoint, Word, Outlook, OneDrive — et sait tirer des données de plus de 400 applications connectées (Snowflake, Salesforce, HubSpot) pour les déposer dans des fichiers locaux. Chaque sous-tâche est routée vers l'un de plus de 20 modèles frontière, ce qui rapproche le produit d'un routeur applicatif — même logique que le Cursor Router côté code, appliquée à la bureautique.

L'architecture est décrite comme hybride en quatre couches, avec une formule qui résume tout : le PC fournit les mains, le cloud Perplexity fournit le cerveau. La conséquence est structurelle, pas contractuelle : le contexte de tout fichier local traité quitte la machine avant qu'une action soit exécutée. Ce n'est pas un défaut de configuration corrigible côté client — c'est le fonctionnement nominal du produit.

🛠 Pourquoi c'est utile à savoir pour Lynxter

La promesse est réelle sur l'administratif support, et c'est là qu'un test aurait du sens. Relances de devis, tri des pièces jointes RMA, mise à jour des tableaux de suivi machines, extraction de champs depuis des mails Outlook vers un tableur : ce sont des tâches où Claude Code n'a pas d'avantage, faute de piloter Excel et Outlook nativement, et où un agent desktop capable de cliquer dans les applications métier gagne. C'est le seul axe sur lequel l'arbitrage se joue.

Mais l'architecture disqualifie une grande partie de nos données. Dossiers clients, plans, documents S300X/S600D sous NDA : tant qu'aucune revue DPA n'a été faite, ces fichiers ne doivent pas passer par un agent dont le fonctionnement nominal envoie leur contenu au cloud d'un tiers. Le découpage à poser si on teste : un périmètre strict de dossiers autorisés (administratif non confidentiel) et rien d'autre — ce qui, dans les faits, réduit fortement l'intérêt du produit.

À 200 $/mois par siège, la comparaison est simple. Face à un poste Claude Code déjà en place et déjà payé, l'écart ne se joue ni sur la qualité de raisonnement ni sur la capacité agentique, mais uniquement sur le pilotage d'applications Office natives. Si le besoin réel est « remplir des tableurs et traiter des mails », un connecteur ciblé ou un script coûtera moins cher qu'un abonnement premium par utilisateur ; si le besoin est diffus et bureautique, il faut mesurer le nombre d'heures réellement économisées avant d'engager un siège annuel.
