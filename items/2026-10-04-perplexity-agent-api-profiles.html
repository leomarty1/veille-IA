Contexte étendu

Perplexity a retiré Sonar Chat Completions le 27 septembre : les appels renvoient désormais une 403 agent_api_migration_required. Le lendemain, l'Agent API reçoit trois primitives. Un Profile est une configuration versionnée sous un seul ID — modèle ou chaîne de repli, instructions système, effort de raisonnement, outils, Skills, connecteurs et budget de pas de la boucle agent. Les Skills sont des capacités sauvegardées (procédure, règles de preuve, format de sortie) réutilisables d'un Profile à l'autre.

Les connecteurs managés se configurent une fois par projet ou API Group, sans repasser URL ni token à chaque requête : le catalogue couvre GitHub, Slack, Google Drive, Datadog, Linear et Notion, et un connecteur peut pointer vers un serveur MCP distant custom. Le schéma reprend celui d'Anthropic (Managed Agents, Skills, connecteurs MCP) ; aucun prix spécifique n'est publié pour ces primitives dans les résultats consultés.

🛠 Pourquoi c'est utile à savoir pour Lynxter

Toute intégration Sonar est cassée depuis le 27 septembre. Action : chercher dans les scripts et Routines Lynxter tout appel à l'endpoint Sonar Chat Completions et le migrer vers l'Agent API, ou le retirer s'il n'est plus utilisé.

Le support MCP distant rend la comparaison possible. Un serveur MCP de documentation S300X/S600D pourrait être branché sur un Profile Perplexity comme sur un agent Managed Agents. Action : si ce serveur existe, l'exposer aux deux et comparer la qualité des réponses de recherche documentaire sur 20 questions de support.
