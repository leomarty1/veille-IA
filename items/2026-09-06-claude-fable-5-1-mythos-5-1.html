Contexte étendu

Anthropic ship Claude Fable 5.1 le 1er septembre 2026, trois mois après Fable 5. La grille tarifaire de tête ne bouge pas — $10 en input, $50 en output par M tokens — et c'est précisément ce qui rend le vrai changement facile à manquer : le cache read tombe de $1 à $0.25 par M tokens. Sur un workload agentique classique, où un contexte stable et volumineux est rejoué à chaque tour d'une boucle, le cache read constitue l'essentiel du volume d'input facturé. Une division par quatre à cet endroit déplace davantage l'économie d'un déploiement qu'une baisse de 10 % sur le prix nominal des tokens.

Sur les benchmarks, Anthropic met délibérément l'accent sur le long-horizon plutôt que sur le code pur. Terminal-Bench 4.0 passe à 55.8 % contre 42.0 % pour Fable 5, et Terminal-Bench-Science 0.1 à 52.6 % — plus du double de Fable 5 (24.7 %), et surtout très au-dessus d'Opus 5 à 29.0 % sur le même test. Anthropic revendique un doublement sur la recherche scientifique agentique et un quasi-doublement sur les workflows métier. Côté logiciel, la maison publie SWE-bench Pro à 81.2 et CursorBench 3.2.0 à 73.4 %. Point de vigilance méthodologique : Anthropic ne publie aucun score SWE-bench Verified pour Fable 5.1. Les « 95 % » relayés ici et là proviennent de leaderboards tiers, pas de l'éditeur — les traiter comme un chiffre officiel serait une erreur, et c'est la raison pour laquelle ce modèle n'entre pas dans le graphe SWE-bench Verified de ce site avec un point « officiel ».

Mythos 5.1 mérite d'être compris pour ce qu'il est : non pas un modèle plus puissant, mais le même modèle sous-jacent livré avec des garde-fous desserrés sur la cybersécurité et la biologie. L'accès passe par invitation, via le Cyber Verification Program (défenseurs en sécurité offensive/défensive) et le Life Sciences Verification Program (recherche et développement en sciences du vivant), au même tarif de $10/$50. C'est la formalisation d'une stratégie que la concurrence adopte la même semaine — Google gate sa variante Gemini 3.8 Flash Cyber derrière le programme Fairwind, OpenAI ouvre GPT-6 Astra aux payants dans une version qui refuse les prompts cyber. Trois acteurs, trois façons de séparer capacité brute et population autorisée, à quarante-huit heures d'intervalle.

🎯 Pourquoi c'est important pour Lynxter

La baisse du cache read est directement monnayable sur ton usage support. Un agent de support S300X/S600D fonctionne avec un préambule lourd et stable — documentation machine, arbres de panne, procédures de calibration, historiques de tickets — rejoué à chaque question. C'est le profil exact que le prompt caching couvre, et donc le profil exact où une division par quatre du cache read se voit sur la facture. L'action concrète : reprendre les Routines Cowork et les agents Claude Code, vérifier que les blocs stables sont bien placés en tête de prompt (le cache est un préfixe : tout ce qui varie doit venir après), puis mesurer avant/après plutôt que supposer.

L'outil de mesure est arrivé la même semaine. Claude Code 2.1.260 ajoute au /cost et au status line la cause probable d'un cache miss — définitions d'outils modifiées, system prompt changé, TTL dépassé. Sans ça, un cache read bon marché reste théorique : il suffit d'un outil MCP ajouté en cours de session pour invalider le préfixe et repayer plein tarif sans s'en apercevoir. Avec ça, l'audit devient une opération de dix minutes.

Sur le choix de modèle, rester factuel. Fable 5.1 progresse fortement sur le long-horizon agentique, pas sur le code court. Si ton usage dominant est le diagnostic multi-étapes — lire un log, croiser une doc, proposer une procédure — le gain Terminal-Bench est pertinent. S'il s'agit de générer des patchs courts, l'absence de SWE-bench Verified officiel interdit toute comparaison propre avec la génération précédente : benchmarke sur tes propres tickets plutôt que sur les chiffres d'annonce.
