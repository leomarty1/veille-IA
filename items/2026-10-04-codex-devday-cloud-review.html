Contexte étendu

La DevDay 2026 (29 septembre) déplace Codex dans le cloud. Un workspace n'est plus attaché à la machine qui l'a lancé : il se reprend depuis un autre ordinateur, depuis un iPhone ou depuis une autre instance, en conservant les réglages et permissions que l'équipe a approuvés. Le Codex CLI rafraîchi ajoute la délégation de tâches parallèles et leur suivi — lancement vocal, vues d'agents, reprise de session, isolation par git worktrees — et le changelog Codex du 2 octobre ajoute l'historique du command center d'agents et les sessions sans projet.

Code Review fait des pull requests une surface d'inspection dans l'app desktop, avec des revues cloud lancées automatiquement : le service est en GA sur GitHub et en preview sur les merge requests GitLab. Codex Security Cloud scanne dépôts et nouveaux commits en continu, déduplique les findings, prépare des correctifs et accède par défaut aux modèles cyber d'OpenAI via Daybreak Blue. La page DevDay d'OpenAI n'a pas pu être lue directement (egress bloqué) ; les détails sont recoupés par plusieurs comptes rendus indépendants.

Face à Claude Code, l'équivalent fonctionnel existe en partie : sessions cloud, /code-review avec --max-findings depuis la 2.1.288, gh api intégré aux sessions cloud. Ce qui manque côté Anthropic, c'est une revue automatique déclenchée sur chaque PR côté serveur et un support GitLab natif. Cursor a pris ce créneau la semaine précédente avec ses Bots et rollouts. Les trois outils convergent sur l'agent qui tourne hors du poste ; la différenciation passe désormais par l'intégration à la forge de code.

🎯 Pourquoi c'est important pour Lynxter

Tester la revue automatique sur un vrai dépôt avant d'arbitrer. Action : choisir le dépôt d'outillage ou de scripts firmware le plus actif, faire passer les cinq dernières PR dans Codex Code Review et dans /code-review --max-findings all, et compter findings utiles et faux positifs par PR.

La forge décide en partie. Si le code Lynxter est sur GitLab, Codex Code Review n'y est qu'en preview, et Claude Code n'a pas de revue serveur native. Action : vérifier où sont hébergés les dépôts concernés avant tout essai, et ne pas engager d'abonnement sur une fonction en preview.

Le workspace repris depuis un téléphone recoupe les Routines. Le cas d'usage « lancer une tâche au bureau, la suivre en déplacement chez un client » est déjà couvert côté Claude par les sessions cloud. Action : noter ce point dans la comparaison outillage, sans changer d'outil pour lui seul.
