Contexte étendu

Muse Code est le premier produit commercial de Meta Superintelligence Labs, l'unité bâtie par Alexandr Wang après l'acquisition de Scale AI. Le format est celui que Claude Code et Codex ont installé : un agent qui vit dans le terminal, s'installe en une commande, et prend en charge des tâches d'ingénierie complètes sur de gros dépôts plutôt que des complétions ligne à ligne. Les primitives sont familières à qui utilise Claude Code — sous-agents parallèles exécutés dans des worktrees git isolés quand la tâche se décompose, event log résistant aux crashes pour reprendre un travail interrompu, agents d'arrière-plan persistants pour les jobs longs. La beta couvre macOS et Linux. Le modèle qui l'anime, Muse Spark 1.2, a été co-entraîné avec l'agent, approche destinée à améliorer la planification et la gestion du contexte plutôt que la génération de code isolée.

Les chiffres publiés par Meta placent Spark 1.2 en progression nette sur son prédécesseur et en embuscade derrière la frontière. Sur Terminal-Bench 2.1, il atteint 82.9 % contre 76.2 % pour Muse Spark 1.1, soit +6.7 pts ; sur DeepSWE v1.1, 59.3 % contre 53.0 %, soit +6.3 pts. Positionné face à la concurrence, il reste derrière Claude Opus 5 (86.7 % sur Terminal-Bench 2.1) — 3.8 points d'écart — et passe légèrement devant GPT-5.6 Terra. Sur le prix, Meta se place sous la frontière : $1,25 en entrée et $4,25 en sortie par million de tokens, reprenant la grille de Muse Spark 1.1, soit environ le quart du tarif d'entrée d'Opus 5.

Deux réserves qualifient sérieusement ce tableau. La première est méthodologique : Vals AI, qui fait passer chaque modèle dans un harness commun, classe Muse Spark 1.2 14ᵉ sur 50 sur Terminal-Bench — quand la configuration agent propriétaire de Meta le plaçait 2ᵉ. L'écart entre les deux mesures est précisément la valeur ajoutée par le harnais du vendeur, et il est ici considérable ; c'est un rappel utile que les scores agentiques publiés par un fournisseur mesurent le couple modèle+agent, pas le modèle. La seconde est contractuelle : le contributor tier, à environ $0,10 en entrée et $0,20 en sortie — de l'ordre de 12× moins cher que le tarif standard — n'est pas une remise commerciale mais un troc de données : Meta se réserve l'usage des prompts et des complétions comme matériau d'entraînement. Le prix affiché ne se lit pas sans cette clause.

🎯 Pourquoi c'est important pour Lynxter

Le contributor tier est disqualifié pour tout ce qui compte chez Lynxter, et il faut le dire explicitement en interne. À ~$0,10/$0,20 par M tokens, l'écart avec Opus 5 est tel qu'un développeur ou un prestataire peut être tenté de l'activer « juste pour tester » sur un dépôt réel. Or la contrepartie est que Meta se réserve l'usage des prompts et des complétions comme données d'entraînement — ce qui, pour du firmware S300X/S600D, des paramètres de calibration ou des tickets clients nominatifs, est une sortie de périmètre pure et simple. Action : inscris explicitement le tier contributor de Muse Code dans la liste des services interdits sur les dépôts internes, au même titre que les autres offres gratuites contre données. Le tier standard ($1,25/$4,25), lui, reste évaluable — c'est environ le quart du tarif d'entrée d'Opus 5, ce qui en fait un candidat légitime pour du batch non sensible (documentation publique, prototypes jetables, scripts de démonstration).

L'écart Vals AI est le chiffre à retenir de toute l'annonce, et il vaut comme méthode générale. Passer du 2ᵉ rang (harness maison Meta) au 14ᵉ sur 50 (harness commun Vals AI) ne signifie pas que Meta triche, mais que l'agent et le modèle ne se mesurent pas séparément — et que le score annoncé par un vendeur intègre son propre outillage. Applique la règle à toutes tes décisions d'outillage : un score Terminal-Bench ou SWE-bench publié par un fournisseur avec son agent n'est comparable qu'à un autre score obtenu dans le même harnais. Benchmark concret à monter : sélectionne trois tâches d'audit firmware déjà passées en Claude Code avec un résultat connu, rejoue-les en Muse Code tier standard, et compare le taux de réussite au premier essai et le nombre d'allers-retours nécessaires — pas le score benchmark. Sur trois tâches, tu auras un signal plus fiable que n'importe quel classement publié.

Stratégiquement, l'entrée de Meta confirme que l'agent de terminal est le format de référence, et cela renforce ton pari actuel plutôt qu'il ne le fragilise. Trois acteurs frontière — Anthropic, OpenAI, Meta — convergent désormais sur la même forme : CLI, sous-agents parallèles en worktrees isolés, persistance d'état, reprise après crash. Ce que tu as construit autour de Claude Code (routines, sous-agents, conventions CLAUDE.md) se transpose conceptuellement, ce qui réduit le coût d'un éventuel changement de fournisseur, mais aucune raison de bouger aujourd'hui : Opus 5 garde 3.8 points d'avance sur Terminal-Bench 2.1, l'écart réel est plus large sous harnais commun, et Muse Code est en beta. La bonne posture est de surveiller la trajectoire — un Spark 1.3 qui grimperait dans le classement Vals AI serait le vrai signal — pas de piloter sur l'annonce.
