Claude Fable 5.2 sort, 20 % moins cher ; Claude Code corrige de nouvelles failles

Anthropic sort Claude Fable 5.2, plus fort et moins cher que Fable 5.1. Pour nous, il ne remplace pas Opus 5.5. L'action de la semaine reste la mise à jour de Claude Code, qui corrige plusieurs failles.

  • 5 annonces retenues
  • 9 éditeurs suivis
  • Lecture : ~2 min
  • Comparateur de modèles

En 30 secondes

  1. Claude Fable 5.2 sort à 8 $ / 40 $ par million de tokens, 20 % de moins que Fable 5.1. Il reste deux fois plus cher qu'Opus 5.5.
  2. Claude Code 2.1.325 corrige plusieurs contournements des permissions. Les commandes du bac à sable redemandent aussi la permission par défaut.
  3. Meta sort Muse Ember, un petit modèle au prix de Claude Haiku 5.5. Rien de nouveau chez Mistral cette semaine.

Pour Lynxter cette semaine

Ce que ces annonces changent pour nous. Propositions à valider : rien n'est engagé sans feu vert.

  • À faire

    Passer Claude Code en version 2.1.325 ou plus

    Ces versions corrigent plusieurs cas où une commande échappait au contrôle des permissions. Elles corrigent aussi une fuite possible de jetons de connexion vers un autre serveur. Pour vérifier, taper claude --version dans un terminal.

    Qui : Chaque utilisateur de Claude CodeVoir l'annonce ↓
  • À surveiller

    Regarder si nos routines s'arrêtent pour demander une permission

    Depuis la 2.1.325, une tâche planifiée demande une validation avant de lancer certaines compétences. Les commandes du bac à sable demandent aussi la permission par défaut. Si une de nos routines s'appuie sur l'un de ces cas, elle peut se bloquer : à confirmer à sa prochaine exécution.

  • À surveiller

    Garder Opus 5.5 pour nos routines malgré Fable 5.2

    Fable 5.2 dépasse Opus 5.5 sur la plupart des tests d'Anthropic, mais coûte deux fois plus. Anthropic conseille lui-même Opus 5.5 pour les tâches courantes. Dans Claude Code, un choix « Fable 5.1 » enregistré passe tout seul à Fable 5.2.

    Muse Ember et Gemini sont hors charte. L'hébergement de Managed Agents chez soi vise les entreprises qui bâtissent leurs propres agents, ce que nous ne faisons pas.

Claude Code 2.1.325 : nouvelles failles de permissions corrigées, le bac à sable redemande la permission

Quatre versions de Claude Code sortent du 9 au 13 novembre. Elles corrigent plusieurs contournements des permissions et une fuite possible de jetons de connexion. Depuis la 2.1.325, les commandes du bac à sable et certaines tâches planifiées demandent la permission par défaut.

À faire

Vérifier que chaque poste est en 2.1.325 ou plus (claude --version dans un terminal).

Les chiffres
  • 2.1.325 (13 nov.) : faille corrigée dans le décodage des réponses compressées zstd ; certaines commandes Bash composées et certaines règles allow passaient sans contrôle
  • 2.1.325 : les commandes Bash du bac à sable suivent le flux normal des permissions (sandbox.autoAllowBashIfSandboxed: true pour garder l'ancien comportement)
  • 2.1.325 : les tâches planifiées et /loop demandent une validation avant une compétence qui déclare allowed-tools ou des hooks ; ajouter Skill(nom) à permissions.allow
  • 2.1.323 (12 nov.) : Write et Edit ne peuvent plus écrire sur un chemin protégé par une règle Read en deny ; claude -p s'arrête si un réglage du bac à sable est invalide
  • 2.1.323 : contexte supposé de 1 million de tokens pour un modèle inconnu (au lieu de 200 000)
  • 2.1.322 (10 nov.) : mode rapide sur Vertex
  • 2.1.321 (9 nov.) : les jetons OAuth d'un serveur MCP ne suivent plus une redirection vers un autre hôte ; une commande Bash en lecture seule ne sort plus du bac à sable sans demander

Sources : code.claude.com/changelog#2-1-325 · code.claude.com/changelog#2-1-323 · code.claude.com/changelog#2-1-321

Les mots du brief

Survolez ou touchez un mot souligné en pointillés pour sa définition. Lexique complet →

Claude Code
Assistant d'Anthropic qui travaille dans un terminal ou un éditeur : code, fichiers, automatisations.
Prix « $2/$10 »
Prix pour un million de tokens (≈ 750 000 mots) : le 1er chiffre pour ce que le modèle lit, le 2e pour ce qu'il écrit.
Bac à sable (sandbox)
Environnement isolé où l'IA exécute du code sans pouvoir toucher au reste du système.
Routine
Tâche Claude planifiée qui tourne seule dans le cloud, sans PC allumé (ce brief en est une).
Charte IA Lynxter
Nos règles internes d'usage de l'IA : quelles données, dans quels outils.
Agent
IA qui enchaîne seule plusieurs actions (chercher, lire, écrire, exécuter) pour atteindre un objectif.
Token
Morceau de mot (environ ¾ d'un mot). C'est l'unité que les IA lisent, écrivent et facturent.
Fenêtre de contexte
Quantité de texte que le modèle garde en tête d'un coup. 1 million de tokens ≈ 1 500 pages.
Terminal-Bench
Test où l'IA accomplit seule des tâches techniques complètes en ligne de commande : installer, configurer, déboguer.
OSWorld
Test où l'IA pilote un vrai ordinateur (clics, fenêtres, logiciels) pour réaliser une tâche de bureau.
Humanity's Last Exam
Questions d'experts très difficiles, dans des dizaines de disciplines.
Mode rapide
Option payante où le modèle écrit sa réponse plus vite, contre un prix par token plus élevé.
Zéro rétention (ZDR)
Option où l'éditeur ne conserve pas les données envoyées au modèle.
API
Accès direct au modèle depuis un logiciel ou un script, facturé à l'usage (au token).
Hook
Point d'accroche où un plugin réagit à un événement de Claude Code, par exemple juste avant l'utilisation d'un outil.
MCP
Standard ouvert pour brancher une IA sur un outil ou une base de données (un « connecteur »).
Claude Managed Agents
Service d'Anthropic qui fait tourner des agents Claude sur ses propres serveurs, pour les entreprises qui en construisent.
Cursor
Éditeur de code avec IA intégrée, concurrent de Claude Code.
