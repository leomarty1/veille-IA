Claude Code renforce encore son bac à sable ; Mistral publie les poids de Large 4

Ce brief couvre deux semaines, faute d'édition le 25 octobre. L'action pour nous reste la mise à jour de Claude Code, qui corrige d'autres failles de son bac à sable. Mistral publie enfin les poids de son grand modèle, trop lourd pour un petit serveur.

  • 8 annonces retenues
  • 9 éditeurs suivis
  • Lecture : ~3 min
  • Comparateur de modèles

En 30 secondes

  1. Claude Code sort onze versions. Les 2.1.309 et 2.1.314 bouchent de nouveaux trous du bac à sable : chaque poste doit être au moins en 2.1.314.
  2. Mistral rend Mistral Large 4 téléchargeable et baisse son prix de moitié. Il faut au moins quatre cartes graphiques de centre de données pour le faire tourner.
  3. OpenAI sort GPT-6.1 Terra, deux fois moins cher que le modèle qu'il remplace. Google réserve Gemini 4 Carbon à des équipes de cybersécurité.

Pour Lynxter cette semaine

Ce que ces annonces changent pour nous. Propositions à valider : rien n'est engagé sans feu vert.

Claude Code 2.1.304 à 2.1.316 : de nouveaux trous du bac à sable bouchés

Onze versions de Claude Code sortent du 19 au 31 octobre. La 2.1.309 empêche les fichiers de démarrage du terminal de s'exécuter hors du bac à sable. La 2.1.314 applique le bac à sable quand on reprend une session dans un dossier de travail séparé.

À faire

Vérifier que chaque poste est en 2.1.314 ou plus (claude --version dans un terminal).

Les chiffres
  • 2.1.309 (22 oct.) : sur macOS et Linux, les fichiers de démarrage du shell s'exécutaient hors bac à sable avant chaque commande Bash : corrigé. Les commandes du bac à sable ne peuvent plus modifier le fichier passé avec --mcp-config. Les motifs denyWrite de macOS s'appliquent aussi à travers un lien symbolique
  • 2.1.309 : sous Linux, les interdictions d'écriture du bac à sable ne sautent plus quand une commande en arrière-plan survit à la session
  • 2.1.314 (30 oct.) : le bac à sable s'applique à un worktree repris par claude -p --resume ou --continue ; les routines dans le cloud chargent les plugins activés sur le compte claude.ai
  • 2.1.312 (27 oct.) : niveau d'effort réglable pour une routine qui tourne dans le cloud
  • 2.1.316 (31 oct.) : mode rapide d'Opus 4.8 déprécié ; une tâche planifiée dans le cloud stoppée par le mode auto est désormais marquée en échec ; CLAUDE_CODE_SUBAGENT_EFFORT fixe l'effort des sous-agents
  • 2.1.305 (20 oct.) : sandbox.allowNestedUserNamespaces permet de lancer Chromium ou podman dans le bac à sable sous Linux, au prix de ses protections de fichiers

Sources : code.claude.com/changelog#2-1-309 · code.claude.com/changelog#2-1-314 · code.claude.com/changelog#2-1-316

Anthropic22 oct. 2026

Les Skills de Claude deviennent un standard neutre, confié à la Linux Foundation

Anthropic donne le format des Skills à l'Agentic AI Foundation, qui gère déjà le protocole MCP. Selon Anthropic, plus de 70 outils l'ont adopté, dont ChatGPT, Cursor et GitHub Copilot. Une compétence écrite pour Claude devrait donc rester réutilisable ailleurs.

Rien à faire

Rien à changer : nos Skills continuent de fonctionner. Le futur guide de sécurité pour installer des Skills sera à lire.

Sources : anthropic.com/news/donating-agent-skills-to-the-agentic-ai-foundation

Les mots du brief

Survolez ou touchez un mot souligné en pointillés pour sa définition. Lexique complet →

Claude Code
Assistant d'Anthropic qui travaille dans un terminal ou un éditeur : code, fichiers, automatisations.
Bac à sable (sandbox)
Environnement isolé où l'IA exécute du code sans pouvoir toucher au reste du système.
Charte IA Lynxter
Nos règles internes d'usage de l'IA : quelles données, dans quels outils.
Token
Morceau de mot (environ ¾ d'un mot). C'est l'unité que les IA lisent, écrivent et facturent.
Préversion (preview, bêta)
Fonction encore en test : elle peut changer ou disparaître. À éviter pour un usage critique.
Fenêtre de contexte
Quantité de texte que le modèle garde en tête d'un coup. 1 million de tokens ≈ 1 500 pages.
Infrastructure locale
Serveurs Lynxter (prévus) où faire tourner des modèles ouverts : la seule voie prévue pour les données sensibles.
Mixture of Experts (MoE)
Architecture où seule une partie du modèle travaille à chaque mot : plus rapide et moins cher à faire tourner.
Paramètres (taille d'un modèle)
Taille d'un modèle, en milliards (« 30B »). Plus il y en a, plus il faut de matériel pour le faire tourner.
API
Accès direct au modèle depuis un logiciel ou un script, facturé à l'usage (au token).
Prix « $2/$10 »
Prix pour un million de tokens (≈ 750 000 mots) : le 1er chiffre pour ce que le modèle lit, le 2e pour ce qu'il écrit.
Terminal-Bench
Test où l'IA accomplit seule des tâches techniques complètes en ligne de commande : installer, configurer, déboguer.
Niveau d'effort
Réglage qui dit au modèle combien réfléchir : bas = rapide et économique, haut = plus soigné.
Codex
L'assistant de programmation d'OpenAI, concurrent de Claude Code.
Routine
Tâche Claude planifiée qui tourne seule dans le cloud, sans PC allumé (ce brief en est une).
Plugin / mod
Extension qui ajoute des compétences ou change le comportement d'un outil.
Dépréciation / retrait
Un modèle déprécié marche encore mais sa date de fin est annoncée. Après le retrait, les appels échouent.
Mode auto
Mode de Claude Code où un filtre automatique accepte seul les actions jugées sans risque, au lieu de vous demander à chaque fois.
Agent
IA qui enchaîne seule plusieurs actions (chercher, lire, écrire, exécuter) pour atteindre un objectif.
Skills
Fiches d'instructions qu'un agent charge à la demande pour une tâche précise.
MCP
Standard ouvert pour brancher une IA sur un outil ou une base de données (un « connecteur »).
Cursor
Éditeur de code avec IA intégrée, concurrent de Claude Code.
Licence Apache 2.0
Licence libre permissive : elle autorise l'usage, la modification et l'usage commercial, à condition de conserver les mentions de l'auteur et de la licence.
