Claude Code corrige son bac à sable ; Meta et Mistral publient des modèles ouverts

Pas de nouveau modèle Claude cette semaine. L'action pour nous est une mise à jour de Claude Code, qui bouche plusieurs trous de son bac à sable. Côté modèles ouverts, Meta publie un très gros modèle et Mistral de petits modèles de prévision.

  • 13 annonces retenues
  • 9 éditeurs suivis
  • Lecture : ~4 min
  • Comparateur de modèles

En 30 secondes

  1. Claude Code sort cinq versions. La 2.1.299 empêche plusieurs contournements du bac à sable : chaque poste doit être au moins en 2.1.299.
  2. Meta sort Muse Wonder, au niveau des meilleurs selon ses tests, et Muse Spark Open, un modèle ouvert qui demande environ 700 Go de mémoire graphique.
  3. Mistral publie Timestral, de petits modèles ouverts qui prévoient l'évolution de mesures. Gemini 4 Argon est ouvert à tous les clients de l'API Google.

Pour Lynxter cette semaine

Ce que ces annonces changent pour nous. Propositions à valider : rien n'est engagé sans feu vert.

Anthropic14 oct. 2026Important pour nous

Claude Code 2.1.299 à 2.1.303 : plusieurs trous du bac à sable bouchés

Cinq versions de Claude Code sortent du 14 au 18 octobre. La 2.1.299 corrige plusieurs façons de contourner le bac à sable, par exemple lire un dossier interdit en passant par un raccourci de fichier sur Mac. La 2.1.302 évite qu'une routine qui plante à mi-chemin soit relancée depuis le début.

À faire

Vérifier que chaque poste est en 2.1.299 ou plus (claude --version dans un terminal).

Les chiffres
  • 2.1.299 (14 oct.) : sur macOS, une commande dans le bac à sable pouvait lire ou écrire un chemin interdit via un lien symbolique ; elle pouvait aussi écrire dans un dossier --plugin-dir, rechargé hors bac à sable : corrigé
  • 2.1.299 : sous Windows sans Git for Windows, les hooks PreToolUse et PermissionRequest qui échouaient laissaient passer l'action ; ils la bloquent désormais. Les règles deny d'un serveur MCP dont le nom contient un double tiret bas s'appliquent enfin
  • 2.1.299 : compaction automatique d'une conversation de plus de 200 000 tokens laissée inactive environ 54 minutes, avant l'expiration du cache d'une heure ("idleCompaction": false pour la couper)
  • 2.1.300 (14 oct.) : les updatedInput des hooks sont validés comme l'entrée de Claude ; gros envois vers l'API compressés en gzip ; nombreuses corrections Cowork, VS Code et Claude dans Slack
  • 2.1.301 (15 oct.) : en passant à un modèle à plus petite mémoire de travail, la conversation est d'abord résumée par le modèle précédent
  • 2.1.302 (16 oct.) : une routine planifiée qui échouait en cours de route était relancée depuis le début une heure plus tard ou plus, au risque de publier deux fois le même rapport : corrigé. 2.1.303 (18 oct.) : corrections diverses

Sources : code.claude.com/changelog#2-1-299 · code.claude.com/changelog#2-1-300 · code.claude.com/changelog#2-1-301 · code.claude.com/changelog#2-1-302

Modèles ouverts et IA locale

Mistral15 oct. 2026

Timestral : Mistral sort de petits modèles ouverts pour prévoir des courbes de mesures

Mistral lance Timestral, quatre modèles de 5 à 209 millions de paramètres, faits pour prolonger une série de mesures dans le temps. Ils tournent sur un processeur ordinaire, sans carte graphique. Selon Mistral, le plus gros arrive premier sur les trois tests publics de référence du domaine.

À surveiller

Mistral est autorisé par la charte. Ce type d'outil sert à la maintenance prédictive : un sujet que nos clients industriels pourraient évoquer.

Les chiffres
  • Tailles : 5M, 28M, 123M et 209M paramètres ; prévisions probabilistes, plusieurs courbes à la fois, avec variables externes passées et futures
  • Selon Mistral : premier sur GIFT-Eval, TIME et fev-bench ; le modèle 28M bat Chronos-2, environ quatre fois plus gros, sur GIFT-Eval et TIME
  • Selon la presse : jusqu'à 32 768 points d'historique lus et 1 024 points prévus d'un coup ; 10 ms (5M) à 140 ms (209M) par prévision sur un processeur de serveur
  • Licence des poids non vérifiée sur la page de Mistral (egress bloqué)

Sources : mistral.ai/news/timestral · opendatascience.com (presse)

Les mots du brief

Survolez ou touchez un mot souligné en pointillés pour sa définition. Lexique complet →

Claude Code
Assistant d'Anthropic qui travaille dans un terminal ou un éditeur : code, fichiers, automatisations.
Bac à sable (sandbox)
Environnement isolé où l'IA exécute du code sans pouvoir toucher au reste du système.
Modèle ouvert (open weights)
Modèle téléchargeable : on peut le faire tourner sur ses propres serveurs, sans envoyer de données à l'éditeur.
API
Accès direct au modèle depuis un logiciel ou un script, facturé à l'usage (au token).
Routine
Tâche Claude planifiée qui tourne seule dans le cloud, sans PC allumé (ce brief en est une).
Charte IA Lynxter
Nos règles internes d'usage de l'IA : quelles données, dans quels outils.
Token
Morceau de mot (environ ¾ d'un mot). C'est l'unité que les IA lisent, écrivent et facturent.
Agent
IA qui enchaîne seule plusieurs actions (chercher, lire, écrire, exécuter) pour atteindre un objectif.
DeepSWE
Test de programmation sur des tâches de développement longues, cité par Google pour Gemini.
Fenêtre de contexte
Quantité de texte que le modèle garde en tête d'un coup. 1 million de tokens ≈ 1 500 pages.
Terminal-Bench
Test où l'IA accomplit seule des tâches techniques complètes en ligne de commande : installer, configurer, déboguer.
Infrastructure locale
Serveurs Lynxter (prévus) où faire tourner des modèles ouverts : la seule voie prévue pour les données sensibles.
Mixture of Experts (MoE)
Architecture où seule une partie du modèle travaille à chaque mot : plus rapide et moins cher à faire tourner.
Paramètres (taille d'un modèle)
Taille d'un modèle, en milliards (« 30B »). Plus il y en a, plus il faut de matériel pour le faire tourner.
Open source
Logiciel dont le code est public, que chacun peut lire, réutiliser et modifier.
Prix « $2/$10 »
Prix pour un million de tokens (≈ 750 000 mots) : le 1er chiffre pour ce que le modèle lit, le 2e pour ce qu'il écrit.
Cache
Remise quand on renvoie un texte déjà lu par le modèle (instructions, documents) : ce texte est facturé bien moins cher.
Hook
Point d'accroche où un plugin réagit à un événement de Claude Code, par exemple juste avant l'utilisation d'un outil.
MCP
Standard ouvert pour brancher une IA sur un outil ou une base de données (un « connecteur »).
Compaction
Résumé automatique d'une longue conversation, pour libérer de la place dans la mémoire de travail de l'IA.
Cowork
Application de bureau d'Anthropic où Claude travaille sur des dossiers et des outils connectés.
Cursor
Éditeur de code avec IA intégrée, concurrent de Claude Code.
