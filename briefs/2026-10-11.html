Claude Haiku 5.5 : le petit modèle d'Anthropic, environ quatre fois moins cher

Anthropic sort Claude Haiku 5.5, son petit modèle rapide, à un prix environ quatre fois plus bas que Haiku 4.5. Pour nous, l'action de la semaine est ailleurs : une correction de sécurité dans Claude Code. Mistral donne enfin le nom de son nouveau modèle, et ChatGPT passe à GPT-6 pour tous.

  • 15 annonces retenues
  • 9 éditeurs suivis
  • Lecture : ~5 min
  • Comparateur de modèles

En 30 secondes

  1. Claude Haiku 5.5 (7 oct.) coûte environ 75 % de moins que Haiku 4.5 et fait bien mieux sur les tests d'Anthropic. Il reste loin de Sonnet 5.5 sur les tâches longues. Claude Code l'utilise déjà par défaut.
  2. Claude Code reçoit cinq versions. La 2.1.294 corrige des règles automatiques qui laissaient passer ce qu'elles devaient bloquer : chaque poste doit être au moins en 2.1.294.
  3. Mistral Large 4 est en préversion, téléchargeable fin octobre, mais très gros. Anthropic durcit au 12 novembre ses règles pour Claude branché sur une machine physique. ChatGPT passe à GPT-6 pour tous.

Pour Lynxter cette semaine

Ce que ces annonces changent pour nous. Propositions à valider : rien n'est engagé sans feu vert.

  • À faire

    Passer Claude Code en version 2.1.294 ou plus

    La 2.1.294 corrige des règles automatiques rédigées comme des consignes (« bloque les commandes qui… ») qui laissaient passer ce qu'elles devaient bloquer. Pour vérifier, taper claude --version dans un terminal. À savoir aussi : depuis la 2.1.292, nos routines publient leurs pages privées sans demander d'accord.

Claude Code 2.1.292 à 2.1.296 : une correction de sécurité sur les règles automatiques

Cinq versions de Claude Code sortent du 6 au 9 octobre. La 2.1.294 corrige des hooks rédigés comme des consignes qui laissaient passer ce qu'ils devaient bloquer, et la 2.1.295 permet de bloquer l'action quand un hook plante. Haiku 5.5 devient le petit modèle par défaut, et les routines publient leurs pages privées sans demander d'accord.

À faire

Vérifier que chaque poste est en 2.1.294 ou plus (claude --version dans un terminal).

Les chiffres
  • 2.1.292 (6 oct.) : paramètre effort pour l'outil Agent (effort réglable par sous-agent) ; serveurs MCP locaux en protocole 2026-07-28 par défaut ; les routines planifiées et « Run now » publient un artefact privé sans demander d'accord
  • 2.1.293 (7 oct.) : Claude Haiku 5.5 (claude-haiku-5-5) devient le Haiku par défaut ; synchronisation des skills claude.ai toutes les 40 minutes au lieu de 10 hors session
  • 2.1.294 (8 oct.) : les hooks prompt et agent écrits comme des consignes (« Block commands that… ») laissaient passer ce qu'ils devaient bloquer : corrigé
  • 2.1.295 (8 oct.) : onFailure: "block" pour les hooks commande et HTTP (un hook qui ne démarre pas, expire ou sort en erreur bloque l'action) ; prise en charge d'OSC 7501 pour afficher l'état de Claude Code dans le terminal
  • 2.1.296 (9 oct.) : CLAUDE_CODE_WORKFLOW_SUBAGENT_MODEL (un seul modèle pour tous les agents d'un workflow), autoCompactWindow pour les sous-agents, option allow_large de l'outil Read, coûts du cache Sonnet 5.5 recalculés à $0,10/M

Sources : code.claude.com/changelog#2-1-294 · code.claude.com/changelog#2-1-292 · code.claude.com/changelog#2-1-295 · code.claude.com/changelog#2-1-296

OpenAI7 oct. 2026

ChatGPT passe à GPT-6 pour tous, avec des réponses à manipuler

ChatGPT utilise GPT-6 pour tous ses comptes : GPT-6 Sol pour les payants depuis le 7 octobre, GPT-6 Luna pour les gratuits depuis le 8. Ses réponses peuvent maintenant contenir des graphiques, boutons, formulaires ou cartes à manipuler. Selon OpenAI, la réponse avec recherche web commence 44 % plus tôt qu'avec GPT-5.6.

Rien à faire

ChatGPT reste réservé aux données publiques chez nous. Rien à changer.

Les chiffres
  • Plus, Pro, Business, Enterprise : GPT-6 Sol depuis le 7 octobre ; Free et Go : GPT-6 Luna à partir du 8 octobre
  • « Intelligent UI » : activée par l'administrateur dans Enterprise ; seul l'onglet Chat change, pas Work ni Codex
  • Délai avant le début de la réponse avec recherche web : −44 % pour GPT-6 Instant contre GPT-5.6 Instant, selon OpenAI (une version traduite de l'annonce dit −32 %, écart non expliqué)
  • Aucun nouveau modèle dans l'API

Sources : openai.com/index/gpt-6-for-everyone · androidheadlines.com (presse) · propakistani.pk (presse)

Entreprises, sécurité et règles

Anthropic7 oct. 2026

Forfaits Claude Max et Team : des crédits API mensuels inclus

Les abonnés Claude Max et Team reçoivent chaque mois des crédits pour l'API Claude : 100 à 200 $ pour Max, 20 à 100 $ par siège pour Team, plafonnés à 500 $. Ils couvrent l'API et les outils pour construire des agents, mais pas Claude Code ni l'usage supplémentaire des applis. Les crédits non utilisés sont perdus en fin de mois.

Rien à faire

Nous n'intégrons pas d'API dans nos logiciels : ces crédits n'ont pas d'usage chez nous pour l'instant.

Les chiffres
  • Max 5x : $100/mois ; Max 20x : $200/mois ; Team : $20 par siège Standard, $100 par siège Premium, mis en commun et plafonnés à $500/mois
  • Couverts : API Claude, Claude Managed Agents, Claude Agent SDK, playground. Exclus : Claude Code, usage supplémentaire des applis, Bedrock, Google Cloud, Foundry
  • À rattacher à une organisation de la Console ; 7 jours d'abonnement minimum ; pas de report d'un mois sur l'autre
  • Free, Pro et Enterprise non éligibles

Sources : platform.claude.com — crédits API pour les abonnés · platform.claude.com — release notes 7 oct.

Le reste

Anthropic8 oct. 2026

Politique d'usage de Claude : nouvelles règles pour les machines physiques au 12 novembre

Anthropic met à jour sa politique d'usage, applicable le 12 novembre 2026. Claude branché sur un équipement physique autonome exige un opérateur qualifié capable de l'arrêter, et la machine doit rester sûre si Claude se déconnecte. Les interdictions s'étendent aux armes autonomes, aux opérations de tromperie et au suivi de personnes sans leur accord.

À surveiller

Aucun de nos usages listés ne pilote une machine. À relire si un projet relie un jour Claude à une imprimante ou à un équipement de production.

Les chiffres
  • Entrée en vigueur : 12 novembre 2026
  • Armes : logiciels de guidage, composants et armement de drones ou véhicules autonomes explicitement interdits
  • Nouvelle section sur les activités trompeuses : faux comptes, faux sites d'information, opérations d'influence
  • La cruauté gratuite et répétée envers Claude est interdite dans les cas extrêmes

Sources : anthropic.com/news/2026-usage-policy-update

Les mots du brief

Survolez ou touchez un mot souligné en pointillés pour sa définition. Lexique complet →

Claude Code
Assistant d'Anthropic qui travaille dans un terminal ou un éditeur : code, fichiers, automatisations.
Préversion (preview, bêta)
Fonction encore en test : elle peut changer ou disparaître. À éviter pour un usage critique.
Routine
Tâche Claude planifiée qui tourne seule dans le cloud, sans PC allumé (ce brief en est une).
Charte IA Lynxter
Nos règles internes d'usage de l'IA : quelles données, dans quels outils.
Paramètres (taille d'un modèle)
Taille d'un modèle, en milliards (« 30B »). Plus il y en a, plus il faut de matériel pour le faire tourner.
Infrastructure locale
Serveurs Lynxter (prévus) où faire tourner des modèles ouverts : la seule voie prévue pour les données sensibles.
Crédits API
Somme prépayée qui paie l'usage de l'API Claude, facturée sinon à la quantité de texte traitée.
API
Accès direct au modèle depuis un logiciel ou un script, facturé à l'usage (au token).
Token
Morceau de mot (environ ¾ d'un mot). C'est l'unité que les IA lisent, écrivent et facturent.
Fenêtre de contexte
Quantité de texte que le modèle garde en tête d'un coup. 1 million de tokens ≈ 1 500 pages.
OSWorld
Test où l'IA pilote un vrai ordinateur (clics, fenêtres, logiciels) pour réaliser une tâche de bureau.
Terminal-Bench
Test où l'IA accomplit seule des tâches techniques complètes en ligne de commande : installer, configurer, déboguer.
Humanity's Last Exam
Questions d'experts très difficiles, dans des dizaines de disciplines.
GDPval
Test sur des tâches de travail réelles de nombreux métiers (rapports, tableaux), comparées au travail d'experts. Score en points de classement.
Niveau d'effort
Réglage qui dit au modèle combien réfléchir : bas = rapide et économique, haut = plus soigné.
Dépréciation / retrait
Un modèle déprécié marche encore mais sa date de fin est annoncée. Après le retrait, les appels échouent.
Modèle ouvert (open weights)
Modèle téléchargeable : on peut le faire tourner sur ses propres serveurs, sans envoyer de données à l'éditeur.
Mixture of Experts (MoE)
Architecture où seule une partie du modèle travaille à chaque mot : plus rapide et moins cher à faire tourner.
DeepSWE
Test de programmation sur des tâches de développement longues, cité par Google pour Gemini.
GLM
Famille de modèles d'IA de l'éditeur chinois Z.ai, dont plusieurs versions sont des modèles ouverts, téléchargeables librement.
Hook
Point d'accroche où un plugin réagit à un événement de Claude Code, par exemple juste avant l'utilisation d'un outil.
MCP
Standard ouvert pour brancher une IA sur un outil ou une base de données (un « connecteur »).
Agent
IA qui enchaîne seule plusieurs actions (chercher, lire, écrire, exécuter) pour atteindre un objectif.
Codex
L'assistant de programmation d'OpenAI, concurrent de Claude Code.
Claude Managed Agents
Service d'Anthropic qui fait tourner des agents Claude sur ses propres serveurs, pour les entreprises qui en construisent.
Claude Agent SDK
Kit d'Anthropic pour construire ses propres agents, avec le moteur qui fait tourner Claude Code.
Politique d'usage
Règles d'Anthropic qui disent ce qu'on a le droit de faire avec Claude. Tout utilisateur les accepte.
Cache
Remise quand on renvoie un texte déjà lu par le modèle (instructions, documents) : ce texte est facturé bien moins cher.
Prix « $2/$10 »
Prix pour un million de tokens (≈ 750 000 mots) : le 1er chiffre pour ce que le modèle lit, le 2e pour ce qu'il écrit.
Open source
Logiciel dont le code est public, que chacun peut lire, réutiliser et modifier.
Compliance API
Accès réservé aux offres Claude Enterprise qui permet au service conformité d'exporter les conversations et documents de l'entreprise.
Cursor
Éditeur de code avec IA intégrée, concurrent de Claude Code.
