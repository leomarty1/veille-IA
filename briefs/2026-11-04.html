Outils et assistants

Anthropic3 nov. 2026

Claude ajoute un filigrane invisible au texte de trois de ses modèles

Le texte écrit par Claude Mythos 5, Opus 4.7 et Sonnet 4.6 porte désormais une marque invisible, qui permet de reconnaître un texte produit par l'IA. Les modèles 5.5 ne sont pas cités. L'AI Act prévoit ce type de marquage pour les textes produits par l'IA.

Rien à faire

Nos routines tournent sur Opus 5.5, qui n'est pas concerné pour l'instant. À garder en tête si un client demande comment reconnaître un texte écrit par l'IA.

Les chiffres
  • 3 nov. : filigrane sur Claude Mythos 5, Claude Opus 4.7 et Claude Sonnet 4.6, sur les plateformes listées par Anthropic
  • Sur Sonnet 4.6, le texte d'une requête qui change temperature, top_p ou top_k peut ne pas être marqué

Sources : platform.claude.com — release notes 3 nov.

Anthropic3 nov. 2026

Claude Code 2.1.317 et 2.1.318 : plus de garde-fous pour les routines

La 2.1.317 demande l'accord avant qu'un outil web ou terminal envoie l'adresse e-mail du compte sur le réseau. Elle prévient aussi quand une nouvelle routine reçoit des connecteurs qu'on n'a pas demandés. La 2.1.318 avertit dix jours avant l'expiration d'une connexion.

Rien à faire

Rien de plus à faire : ces versions arrivent avec la mise à jour automatique.

Les chiffres
  • 2.1.317 (3 nov.) : /schedule signale les connecteurs ajoutés à une tâche planifiée dans le cloud sans qu'on les ait demandés, et dit comment les retirer
  • 2.1.317 : les tâches planifiées respectent l'environnement par défaut choisi par l'administrateur
  • 2.1.318 (4 nov.) : claude auth status affiche la date de fin de la connexion claude.ai ; claude -p avertit 10 jours avant
  • 2.1.318 : deniedMcpServers bloque aussi les connecteurs des sessions dans le cloud dont l'adresse correspond

Sources : code.claude.com/changelog#2-1-317 · code.claude.com/changelog#2-1-318

Les mots du brief

Filigrane (watermark)
Marque invisible glissée dans un texte ou une image produits par une IA, qu'un outil de détection peut ensuite repérer.
Claude Code
Assistant d'Anthropic qui travaille dans un terminal ou un éditeur : code, fichiers, automatisations.
AI Act
Règlement européen sur l'intelligence artificielle. Ses obligations arrivent par étapes : la transparence sur les contenus générés par IA s'applique depuis le 2 août 2026.
Routine
Tâche Claude planifiée qui tourne seule dans le cloud, sans PC allumé (ce brief en est une).
Connecteur
Lien entre l'IA et un autre logiciel (messagerie, agenda, documents) qui lui permet d'y lire des informations ou d'y agir.
API
Accès direct au modèle depuis un logiciel ou un script, facturé à l'usage (au token).
Cursor
Éditeur de code avec IA intégrée, concurrent de Claude Code.
