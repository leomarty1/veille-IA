Sonnet 5.5 : presque le niveau d'Opus, pour deux fois moins cher

Anthropic, OpenAI et Google sortent chacun un nouveau modèle cette semaine, tous au même prix. Pour nous, la nouvelle utile est Claude Sonnet 5.5 : des résultats proches d'Opus 5.5 pour moitié prix. Et une mise à jour de sécurité de Claude Code à ne pas oublier.

  • 17 annonces retenues
  • 9 éditeurs suivis
  • Lecture : ~5 min
  • Comparateur de modèles

En 30 secondes

  1. Claude Sonnet 5.5 (28 sept.) fait presque jeu égal avec Opus 5.5 sur les tests publiés par Anthropic, et le dépasse sur certains, pour deux fois moins cher. Il devient le Sonnet par défaut de Claude Code.
  2. OpenAI sort GPT-6.1 Sol au même prix que Sonnet 5.5, rend son assistant Codex utilisable depuis un téléphone et lance des agents qui tournent en continu. Google annonce Gemini 4 Argon, réservé pour l'instant à quelques partenaires.
  3. Claude Code reçoit six mises à jour en six jours, dont deux corrections de sécurité : chaque poste doit être au moins en version 2.1.289.

Pour Lynxter cette semaine

Ce que ces annonces changent pour nous. Propositions à valider : rien n'est engagé sans feu vert.

  • À faire

    Vérifier que Claude Code est en version 2.1.289 ou plus

    Elle corrige deux façons de contourner les règles qui interdisent à Claude Code de lire certains fichiers, comme ceux qui contiennent des mots de passe. La mise à jour est en général automatique : claude --version pour vérifier.

Anthropic28 sept. 2026

Claude Sonnet 4.5 sera coupé le 30 novembre

Anthropic annonce la fin de Claude Sonnet 4.5 dans son API au 30 novembre. Seuls les scripts qui appellent ce modèle par son nom sont concernés : Claude Code et Cowork passent d'eux-mêmes aux versions récentes. Pour les développeurs, Sonnet 5.5 refuse aussi quelques réglages que Sonnet 5 acceptait.

À faire

Chercher « sonnet-4-5 » dans nos dépôts et scripts avant mi-novembre, et remplacer par Sonnet 5.5 si besoin.

Les chiffres
  • Dépréciation annoncée le 30 septembre, retrait de l'API le 30 novembre 2026
  • Code qui appelle l'API directement : Sonnet 5.5 refuse la désactivation du raisonnement (thinking: disabled), le choix d'outil forcé (tool_choice) et les réglages de temperature non standard. Détail dans le guide de migration d'Anthropic.

Claude Code : six mises à jour, dont deux corrections de sécurité

Entre le 28 septembre et le 3 octobre, Claude Code passe de la version 2.1.284 à la 2.1.289. Au programme : Sonnet 5.5 par défaut, des « mods » qui modifient le comportement de l'outil, un réglage pour limiter les fournisseurs de modèles autorisés et une revue de code plus complète. La 2.1.289 corrige deux façons de contourner les règles d'interdiction de lecture.

À faire

Vérifier que chaque poste est en 2.1.289 ou plus (claude --version).

Les chiffres
  • 2.1.284 : Sonnet 5.5 par défaut, /mcp reconnect all
  • 2.1.285 : réglage allowedProviders (8 fournisseurs filtrables) et CLAUDE_CODE_DISABLE_WEB_FETCH pour couper l'accès web
  • 2.1.287 : Claude Mods, dont « You should know », un agent qui signale ce qui pourrait vous échapper pendant une session
  • 2.1.288 : /code-review --max-findings, reprise des sous-agents après une coupure
  • 2.1.289 : deux contournements de règles deny corrigés (mod utilisateur sur poste géré, lecture via un lien symbolique)

Sources : code.claude.com/changelog#2-1-284 · code.claude.com/changelog#2-1-287 · code.claude.com/changelog#2-1-289

OpenAI29 sept. 2026

Codex, l'assistant de code d'OpenAI, se pilote depuis un téléphone

À sa conférence DevDay, OpenAI rend Codex utilisable depuis n'importe quel appareil : une tâche lancée au bureau se reprend sur iPhone. Sa revue de code automatique est disponible pour tous sur GitHub (en préversion sur GitLab), et un nouvel outil surveille les dépôts pour proposer des correctifs de sécurité.

À surveiller

Codex est hors cadre pour notre code interne. Si l'équipe dev veut une revue de code automatique, commencer par /code-review dans Claude Code.

Les chiffres
  • Code Review disponible pour tous sur GitHub, merge requests GitLab en préversion
  • Codex Security Cloud : analyse des dépôts et des nouveaux commits, correctifs préparés
  • Codex CLI : tâches en parallèle, lancement vocal, reprise de session

Sources : openai.com/index/devday-2026-recap · rohitai.com — Codex cloud, CLI, Code Review (presse) · hermes-ai.net — DevDay (presse)

OpenAI29 sept. 2026

OpenAI lance les Dots, des agents qui travaillent en continu

Chaque abonné Pro, Business ou Enterprise d'OpenAI peut créer un « Dot » : un agent qui tourne 24 h/24 sur son propre ordinateur dans le cloud, se connecte à plus de 4 000 applications et réagit aux événements. Les actions sensibles restent validées par l'utilisateur.

Rien à faire

Même principe que nos routines Claude, mais chez OpenAI : hors cadre pour nos données internes.

Les chiffres
  • Propulsés par GPT-6 Astra
  • Un Dot par utilisateur Pro, Business, Premium et Enterprise au lancement
  • Utilisables depuis Slack et Microsoft Teams

Les mots du brief

Survolez ou touchez un mot souligné en pointillés pour sa définition. Lexique complet →

Claude Code
Assistant d'Anthropic qui travaille dans un terminal ou un éditeur : code, fichiers, automatisations.
Codex
L'assistant de programmation d'OpenAI, concurrent de Claude Code.
Agent
IA qui enchaîne seule plusieurs actions (chercher, lire, écrire, exécuter) pour atteindre un objectif.
Routine
Tâche Claude planifiée qui tourne seule dans le cloud, sans PC allumé (ce brief en est une).
Cowork
Application de bureau d'Anthropic où Claude travaille sur des dossiers et des outils connectés.
Charte IA Lynxter
Nos règles internes d'usage de l'IA : quelles données, dans quels outils.
Token
Morceau de mot (environ ¾ d'un mot). C'est l'unité que les IA lisent, écrivent et facturent.
Terminal-Bench
Test où l'IA accomplit seule des tâches techniques complètes en ligne de commande : installer, configurer, déboguer.
CursorBench
Test de programmation publié par l'éditeur Cursor, sur des tâches tirées de son logiciel.
Humanity's Last Exam
Questions d'experts très difficiles, dans des dizaines de disciplines.
OSWorld
Test où l'IA pilote un vrai ordinateur (clics, fenêtres, logiciels) pour réaliser une tâche de bureau.
GDPval
Test sur des tâches de travail réelles de nombreux métiers (rapports, tableaux), comparées au travail d'experts. Score en points de classement.
Fenêtre de contexte
Quantité de texte que le modèle garde en tête d'un coup. 1 million de tokens ≈ 1 500 pages.
SWE-bench Verified
Test de programmation : corriger de vrais bugs de projets open source. Saturé en 2026, les éditeurs ne le publient plus.
Prix « $2/$10 »
Prix pour un million de tokens (≈ 750 000 mots) : le 1er chiffre pour ce que le modèle lit, le 2e pour ce qu'il écrit.
Cache
Remise quand on renvoie un texte déjà lu par le modèle (instructions, documents) : ce texte est facturé bien moins cher.
DeepSWE
Test de programmation sur des tâches de développement longues, cité par Google pour Gemini.
API
Accès direct au modèle depuis un logiciel ou un script, facturé à l'usage (au token).
Dépréciation / retrait
Un modèle déprécié marche encore mais sa date de fin est annoncée. Après le retrait, les appels échouent.
Revue de code automatique
L'IA relit une modification de code avant son intégration et signale bugs et risques.
Plugin / mod
Extension qui ajoute des compétences ou change le comportement d'un outil.
Règle d'interdiction (deny)
Réglage qui empêche Claude Code de lire certains fichiers ou de lancer certaines commandes.
Préversion (preview, bêta)
Fonction encore en test : elle peut changer ou disparaître. À éviter pour un usage critique.
Pull request (PR)
Proposition de modification de code soumise à relecture avant d'être intégrée.
CLI
Outil qui s'utilise en ligne de commande, dans un terminal.
MCP
Standard ouvert pour brancher une IA sur un outil ou une base de données (un « connecteur »).
Bac à sable (sandbox)
Environnement isolé où l'IA exécute du code sans pouvoir toucher au reste du système.
Cursor
Éditeur de code avec IA intégrée, concurrent de Claude Code.
