OpenAI sort GPT-6.2, Google sort Gemini 4 Neon ; Claude Code durcit sa sécurité

OpenAI et Google sortent chacun un nouveau modèle, moins cher que le précédent. Pour nous, rien ne change : Opus 5.5 reste notre modèle. L'action de la semaine est la mise à jour de Claude Code, qui protège mieux nos identifiants.

  • 5 annonces retenues
  • 9 éditeurs suivis
  • Lecture : ~2 min
  • Comparateur de modèles

En 30 secondes

  1. Claude Code 2.1.326 à 2.1.330 protège mieux les fichiers de connexion et demande plus souvent la permission. Les tâches planifiées créées dans le terminal peuvent être à reprogrammer.
  2. OpenAI sort GPT-6.2 Astra, 20 % moins cher que GPT-6 Astra, et GPT-6.2 Sol. Google sort Gemini 4 Neon, son modèle intermédiaire.
  3. Anthropic entre en bourse à 83 $ par action. Rien de nouveau chez Mistral ni chez Meta cette semaine.

Pour Lynxter cette semaine

Ce que ces annonces changent pour nous. Propositions à valider : rien n'est engagé sans feu vert.

  • À faire

    Passer Claude Code en version 2.1.330 ou plus

    Ces versions empêchent Claude d'écrire dans les fichiers qui gardent nos connexions. Le bac à sable n'écrit plus dans certains dossiers sensibles. Claude dans Chrome refuse aussi d'envoyer des fichiers d'identifiants. Pour vérifier la version, taper claude --version dans un terminal.

    Depuis la 2.1.329, la plupart des tâches planifiées enregistrées par une ancienne version doivent être reprogrammées. Cela vise les tâches créées dans le terminal, pas a priori les routines de claude.ai : à confirmer à leur prochaine exécution. Les tâches récurrentes peuvent désormais tourner 30 jours au lieu de 7.

Les annonces

Outils et assistants

Anthropic20 nov. 2026Important pour nous

Claude Code 2.1.330 protège mieux nos identifiants ; certaines tâches planifiées sont à reprogrammer

Cinq versions de Claude Code sortent du 16 au 20 novembre. Elles bloquent l'écriture dans les fichiers de connexion et demandent la permission plus souvent. Les tâches planifiées créées avec une ancienne version peuvent devoir être reprogrammées.

À faire

Mettre à jour Claude Code, puis vérifier que nos tâches planifiées tournent encore.

Les chiffres
  • 2.1.326 (16 nov.) : les outils de fichiers refusent d'écrire dans .credentials.json ; le bac à sable n'écrit plus dans certains dossiers sensibles du répertoire personnel (sandbox.filesystem.allowWrite pour en autoriser)
  • 2.1.326 : certaines commandes cp et mv demandent la permission ; le mode « bypass permissions » demande ou refuse certains appels
  • 2.1.327 (17 nov.) : Claude dans Chrome refuse de téléverser certains fichiers d'identifiants ; les commits évitent les fichiers qui contiennent probablement des secrets
  • 2.1.329 (19 nov.) : la plupart des tâches planifiées enregistrées par une version antérieure doivent être reprogrammées dans les nouvelles sessions connectées
  • 2.1.330 (20 nov.) : tâches récurrentes et /loop jusqu'à 30 jours au lieu de 7, tant que la session tourne ; les tâches créées avant restent limitées à 7 jours
  • 2.1.328 : /code-review ne signale plus que les bugs et les écarts au CLAUDE.md ; /simplify pour le reste

Sources : code.claude.com — changelog 2.1.326 · code.claude.com — changelog 2.1.329 · code.claude.com — changelog 2.1.330

Les mots du brief

Survolez ou touchez un mot souligné en pointillés pour sa définition. Lexique complet →

Claude Code
Assistant d'Anthropic qui travaille dans un terminal ou un éditeur : code, fichiers, automatisations.
Bac à sable (sandbox)
Environnement isolé où l'IA exécute du code sans pouvoir toucher au reste du système.
Routine
Tâche Claude planifiée qui tourne seule dans le cloud, sans PC allumé (ce brief en est une).
Charte IA Lynxter
Nos règles internes d'usage de l'IA : quelles données, dans quels outils.
Token
Morceau de mot (environ ¾ d'un mot). C'est l'unité que les IA lisent, écrivent et facturent.
Fenêtre de contexte
Quantité de texte que le modèle garde en tête d'un coup. 1 million de tokens ≈ 1 500 pages.
Terminal-Bench
Test où l'IA accomplit seule des tâches techniques complètes en ligne de commande : installer, configurer, déboguer.
Prix « $2/$10 »
Prix pour un million de tokens (≈ 750 000 mots) : le 1er chiffre pour ce que le modèle lit, le 2e pour ce qu'il écrit.
Codex
L'assistant de programmation d'OpenAI, concurrent de Claude Code.
API
Accès direct au modèle depuis un logiciel ou un script, facturé à l'usage (au token).
Filigrane (watermark)
Marque invisible glissée dans un texte ou une image produits par une IA, qu'un outil de détection peut ensuite repérer.
Cursor
Éditeur de code avec IA intégrée, concurrent de Claude Code.
