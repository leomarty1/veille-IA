Claude Code 2.1.319 : une sortie du bac à sable et deux failles de permissions corrigées

Trois versions de Claude Code sortent du 3 au 6 novembre. La 2.1.319 corrige une sortie du bac à sable et deux cas où une commande passait sans contrôle des permissions. Elle ajoute aussi un réglage qui refuse une action au lieu d'attendre une validation.

À faire

Vérifier que chaque poste est en 2.1.319 ou plus (claude --version dans un terminal).

Les chiffres
  • 2.1.319 (6 nov.) : sortie du bac à sable à la création d'un worktree corrigée ; un préfixe de variables d'environnement construit exprès ne peut plus cacher une partie d'une commande Bash aux contrôles ; une commande sed ne peut plus éviter le contrôle en mode auto ou accept-edits
  • 2.1.319 : les règles deny et ask reconnaissent les commandes écrites avec des mots entre guillemets ; /rewind ne peut plus restaurer ou supprimer un fichier à travers un lien symbolique de dossier
  • 2.1.319 : nouveau réglage permissions.denyInsteadOfPrompting ; une routine dans le cloud garde désormais un connecteur nommé « memory »
  • 2.1.318 (4 nov.) : claude auth status affiche la date de fin de la connexion claude.ai ; les touches tapées juste après un message ne répondent plus à une demande de permission
  • 2.1.317 (3 nov.) : /schedule prévient quand une nouvelle tâche planifiée reçoit des connecteurs non demandés

Sources : code.claude.com/changelog#2-1-319 · code.claude.com/changelog#2-1-318 · code.claude.com/changelog#2-1-317

Les mots du brief

Claude Code
Assistant d'Anthropic qui travaille dans un terminal ou un éditeur : code, fichiers, automatisations.
Bac à sable (sandbox)
Environnement isolé où l'IA exécute du code sans pouvoir toucher au reste du système.
API
Accès direct au modèle depuis un logiciel ou un script, facturé à l'usage (au token).
Token
Morceau de mot (environ ¾ d'un mot). C'est l'unité que les IA lisent, écrivent et facturent.
Fenêtre de contexte
Quantité de texte que le modèle garde en tête d'un coup. 1 million de tokens ≈ 1 500 pages.
Mode auto
Mode de Claude Code où un filtre automatique accepte seul les actions jugées sans risque, au lieu de vous demander à chaque fois.
Routine
Tâche Claude planifiée qui tourne seule dans le cloud, sans PC allumé (ce brief en est une).
Connecteur
Lien entre l'IA et un autre logiciel (messagerie, agenda, documents) qui lui permet d'y lire des informations ou d'y agir.
Préversion (preview, bêta)
Fonction encore en test : elle peut changer ou disparaître. À éviter pour un usage critique.
Paramètres (taille d'un modèle)
Taille d'un modèle, en milliards (« 30B »). Plus il y en a, plus il faut de matériel pour le faire tourner.
Cursor
Éditeur de code avec IA intégrée, concurrent de Claude Code.
