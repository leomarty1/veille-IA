Claude Code pouvait parfois lire des fichiers interdits : passer en 2.1.291

Brief court, deux jours après le précédent. L'essentiel pour nous : une mise à jour de sécurité de Claude Code, à installer. À suivre aussi, deux modèles : Beam, un modèle ouvert, et un nouveau Mistral encore sans détails. OpenAI annonce un filigrane invisible sur ses textes en Europe, sans effet pour nous.

  • 9 annonces retenues
  • 9 éditeurs suivis
  • Lecture : ~4 min
  • Comparateur de modèles

En 30 secondes

  1. Claude Code passe en 2.1.290 puis en 2.1.291, les 5 et 6 octobre. La 2.1.290 bouche plusieurs failles par lesquelles Claude Code pouvait lire des fichiers interdits. La 2.1.291 corrige deux bugs récents. Chaque poste doit passer en 2.1.291.
  2. OpenAI va marquer d'un filigrane invisible le texte de ChatGPT et de Codex en Europe, pour répondre à l'AI Act. Il testera aussi aux États-Unis des publicités affichées pendant la génération d'une image. Rien à changer pour nous.
  3. Deux modèles à suivre : Beam, modèle ouvert de Reflection AI (501 milliards de paramètres), téléchargeable d'ici fin octobre, et un nouveau modèle Mistral annoncé le 6 octobre, sans nom ni détails pour l'instant.

Pour Lynxter cette semaine

Ce que ces annonces changent pour nous. Propositions à valider : rien n'est engagé sans feu vert.

Beam

nouvelle gamme · sorti le 5 oct. 2026

Premier modèle de Reflection AI, orienté code et tâches d'agent. Reflection le dit proche de GLM-5.2, un modèle ouvert chinois, en demandant bien moins de puissance de calcul. Pour l'instant : préversion sur liste d'attente, ni prix, ni téléchargement. Ses scores, non vérifiés, ne sont pas repris ici.

  • Prix (lecture / écriture)non publié
  • Mémoire de travailnon communiqué
  • DisponibilitéPréversion
  • Chez LynxterHors cadre

Aucun score officiel publié pour ce modèle.

À surveiller

Sa préversion en ligne est hors cadre : données publiques seulement. Une fois téléchargeable, il sera candidat pour notre future infrastructure locale, mais il est très gros (501 milliards de paramètres) : attendre sa fiche technique pour connaître le matériel nécessaire.

Les chiffres
  • Architecture : Mixture of Experts, texte seul ; 501 milliards de paramètres, dont 23 milliards actifs par token (titre de la page de Reflection, repris par TechCrunch et MarkTechPost) ; pré-entraînement sur 23 800 milliards de tokens
  • Accès : interface de programmation (API) en bêta, compatible avec celle d'OpenAI, sur liste d'attente et sans prix publié
  • Téléchargement promis « plus tard en octobre » sous licence Apache 2.0, avec un rapport technique, une fiche du modèle et les outils pour le faire tourner
  • Revendication de Reflection : des résultats comparables à GLM-5.2 (Z.ai) en raisonnement, et proches en code et en tâches d'agent, pour 3 à 4 fois moins de calcul d'inférence. Non vérifié de façon indépendante. Repère : GLM-5.2 (environ 750 milliards de paramètres) tourne sur un serveur à 8 cartes graphiques H100 (fiche Hugging Face) ; le matériel exact de Beam reste inconnu
  • Selon Help Net Security (6 octobre), Beam reste derrière les meilleurs modèles ouverts chinois sur les tests de code
  • Mémoire de travail (1 million de tokens annoncé après extension, 256 000 pendant l'entraînement selon les reprises) et scores : versions divergentes dans la presse, à relire sur la fiche du modèle

Sources : reflection.ai — Introducing Beam · techcrunch.com (presse) · helpnetsecurity.com (presse) · marktechpost.com (presse)

Outils et assistants

Anthropic5 oct. 2026Important pour nous

Claude Code 2.1.290 et 2.1.291 : des failles d'accès aux fichiers interdits corrigées

La 2.1.290 du 5 octobre est une grosse mise à jour : 190 changements, environ deux fois plus qu'une version habituelle. Elle bouche plusieurs failles par lesquelles Claude Code pouvait lire des fichiers interdits, et fiabilise les rappels et tâches répétées lancés dans une session. La 2.1.291 du 6 octobre corrige deux bugs récents, dont la perte des derniers messages à la fermeture.

À faire

Vérifier que chaque poste est en 2.1.291 (claude --version dans un terminal) : elle corrige aussi la perte des derniers messages à la fermeture. Nos routines tournent dans le cloud d'Anthropic : a priori rien à faire.

Les chiffres
  • Contournements fermés : un lien échangé pendant la lecture d'une image (macOS et Windows) ou d'un @-mention pouvait faire lire un fichier interdit ; les règles Read deny ne s'appliquaient pas aux images collées ou glissées ; une variable placée devant declare, typeset, export ou readonly contournait une règle deny ou ask
  • En plan mode, le classifieur du mode auto pouvait approuver des outils de connecteur capables de modifier des données, alors que le serveur exigeait une confirmation ; un mod installé par l'utilisateur pouvait lever un garde-fou fixé par l'organisation
  • Les règles d'URL disableClaudeAiConnectors et allowedMcpServers s'appliquent maintenant à toutes les entrées MCP déclarées dans .mcp.json, dans des plugins ou dans des agents (certaines y échappaient)
  • Automatisation : /loop et les rappels reprennent après une compaction (faite à partir de la 2.1.290) ; une tâche planifiée au premier plan se déclenche après son passage en arrière-plan ; une tâche récurrente ne tourne plus une fois de trop à chaque reprise ; en mode headless, --json-schema ne sort plus en erreur si la connexion tombe après la livraison du résultat
  • Nouveautés : claude attach <nom> et claude logs <nom> ; /claude-api managed-agents-onboard prépare des fichiers ant apply depuis une page ou un modèle de la Console (ex. deep-researcher) ; WebFetch signale le texte non lu au-delà de 100 000 caractères et accepte un offset ; les hooks de mods reçoivent agentId, ceiling et serverToolUses
  • Cowork : en session cloud, une réponse pouvait ne jamais se terminer si le conteneur redémarrait juste après l'envoi d'un message ou d'un fichier. Corrigé dans la 2.1.290 ; ces sessions tournent chez Anthropic, a priori sans action de notre part
  • 2.1.291 : réponses aux demandes d'autorisation perdues en session cloud (bug apparu en 2.1.290) ; derniers messages d'une session perdus à la fermeture (bug apparu en 2.1.288)

Sources : code.claude.com/changelog#2-1-290 · code.claude.com/changelog#2-1-291 · github.com/anthropics/claude-code — v2.1.290

Entreprises, sécurité et règles

OpenAI5 oct. 2026

Le texte de ChatGPT et de Codex portera un filigrane invisible en Europe

OpenAI présente textGrain : l'IA oriente légèrement le choix de ses mots, et seul un détecteur muni d'une clé secrète repère cette signature. En Europe, il sera appliqué d'office au texte de ChatGPT et de Codex dans les semaines qui viennent, pour répondre à l'AI Act. Le détecteur n'est pas public : il est réservé à des chercheurs et organismes approuvés.

Rien à faire

Nos usages de ChatGPT sont concernés : leurs textes porteront ce filigrane. Rien à changer : le filigrane n'identifie pas l'utilisateur et le détecteur n'est pas public.

Les chiffres
  • Détection, selon OpenAI : environ 80 % des passages de 200 tokens (environ 150 mots) et 95 % des passages de 400 tokens (environ 300 mots), pour 1 % de faux positifs, en conditions favorables
  • Plus fragile sur les maths, les textes courts et les traductions. Sur des passages de 400 tokens (environ 300 mots) en anglais, remplacer 10 % des mots par des synonymes fait passer la détection d'environ 92 % à 66 % ; à 25 %, elle tombe à 17 %
  • Interface de programmation (API) : option ouverte dans le monde entier depuis le 5 octobre sur certains modèles, à activer dans les réglages, désactivée par défaut
  • Le filigrane survit au copier-coller et n'identifie pas l'utilisateur
  • AI Act, article 50 : marquage des contenus générés lisible par une machine, applicable depuis le 2 août 2026

Sources : openai.com — Our approach to EU text provenance rules · openai.com — article technique textGrain (PDF) · techcrunch.com (presse) · thenewstack.io — filigrane désactivé par défaut dans l'API (presse)

En bref

  • Anthropic — Cresta et le Claude Agent SDK. Cresta bâtit sur le Claude Agent SDK un outil qui crée des agents de relation client à partir d'une description. Selon Cresta, il divise environ par deux le temps de première mise en service. claude.com/blog — Cresta
  • OpenAI — Publicités dans ChatGPT. OpenAI testera aux États-Unis, plus tard en octobre, des publicités en images affichées pendant la génération d'une image. Elles seront signalées comme publicité et séparées de l'image produite. openai.com — new ChatGPT ads format
  • OpenAI — Codex plus rapide. Selon Thibault Sottiaux (OpenAI), GPT-6 Astra et GPT-6.1 Sol répondent environ 50 % plus vite par défaut pour les abonnés ChatGPT, Codex compris. Première d'une série d'améliorations annoncées jour après jour ; gain non vérifié. x.com — message de Thibault Sottiaux (5 oct.) · sans annonce officielle
  • OpenAI — Codex : vérification automatique gratuite. Pour les abonnés ChatGPT, l'agent qui approuve ou bloque les actions risquées de Codex (Auto-review) ne compte plus dans le quota du forfait. community.openai.com — annonce du 6 octobre
  • Cohere — Cohere North 2. Nouvelle version de la plateforme d'agents de Cohere pour les entreprises : mémoire entre les sessions, plafonds de dépense par utilisateur, installation possible sur site. cohere.com — North 2

Les mots du brief

Survolez ou touchez un mot souligné en pointillés pour sa définition. Lexique complet →

Claude Code
Assistant d'Anthropic qui travaille dans un terminal ou un éditeur : code, fichiers, automatisations.
Filigrane (watermark)
Marque invisible glissée dans un texte ou une image produits par une IA, qu'un outil de détection peut ensuite repérer.
Codex
L'assistant de programmation d'OpenAI, concurrent de Claude Code.
AI Act
Règlement européen sur l'intelligence artificielle. Ses obligations arrivent par étapes : la transparence sur les contenus générés par IA s'applique depuis le 2 août 2026.
Paramètres (taille d'un modèle)
Taille d'un modèle, en milliards (« 30B »). Plus il y en a, plus il faut de matériel pour le faire tourner.
Routine
Tâche Claude planifiée qui tourne seule dans le cloud, sans PC allumé (ce brief en est une).
Licence Apache 2.0
Licence libre permissive : elle autorise l'usage, la modification et l'usage commercial, à condition de conserver les mentions de l'auteur et de la licence.
Préversion (preview, bêta)
Fonction encore en test : elle peut changer ou disparaître. À éviter pour un usage critique.
Charte IA Lynxter
Nos règles internes d'usage de l'IA : quelles données, dans quels outils.
Token
Morceau de mot (environ ¾ d'un mot). C'est l'unité que les IA lisent, écrivent et facturent.
GLM
Famille de modèles d'IA de l'éditeur chinois Z.ai, dont plusieurs versions sont des modèles ouverts, téléchargeables librement.
Infrastructure locale
Serveurs Lynxter (prévus) où faire tourner des modèles ouverts : la seule voie prévue pour les données sensibles.
Mixture of Experts (MoE)
Architecture où seule une partie du modèle travaille à chaque mot : plus rapide et moins cher à faire tourner.
API
Accès direct au modèle depuis un logiciel ou un script, facturé à l'usage (au token).
Modèle ouvert (open weights)
Modèle téléchargeable : on peut le faire tourner sur ses propres serveurs, sans envoyer de données à l'éditeur.
Règle d'interdiction (deny)
Réglage qui empêche Claude Code de lire certains fichiers ou de lancer certaines commandes.
Plan mode
Mode de Claude Code où il prépare un plan d'action sans rien modifier, puis attend votre accord avant d'agir.
Mode auto
Mode de Claude Code où un filtre automatique accepte seul les actions jugées sans risque, au lieu de vous demander à chaque fois.
Connecteur
Lien entre l'IA et un autre logiciel (messagerie, agenda, documents) qui lui permet d'y lire des informations ou d'y agir.
MCP
Standard ouvert pour brancher une IA sur un outil ou une base de données (un « connecteur »).
Plugin / mod
Extension qui ajoute des compétences ou change le comportement d'un outil.
Agent
IA qui enchaîne seule plusieurs actions (chercher, lire, écrire, exécuter) pour atteindre un objectif.
Compaction
Résumé automatique d'une longue conversation, pour libérer de la place dans la mémoire de travail de l'IA.
Mode headless
Claude Code lancé sans conversation à l'écran, par un script ou une tâche automatique, qui renvoie directement son résultat.
WebFetch
Outil de Claude Code qui télécharge et lit une page web à la demande.
Hook
Point d'accroche où un plugin réagit à un événement de Claude Code, par exemple juste avant l'utilisation d'un outil.
Cowork
Application de bureau d'Anthropic où Claude travaille sur des dossiers et des outils connectés.
Faux positif
Erreur d'un détecteur qui signale à tort quelque chose : par exemple, un texte écrit par un humain jugé produit par une IA.
Claude Agent SDK
Kit d'Anthropic pour construire ses propres agents, avec le moteur qui fait tourner Claude Code.
SDK
Bibliothèque de code fournie par l'éditeur pour appeler son API depuis un programme.
