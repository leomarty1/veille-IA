Lexique

Les mots de la veille, en clair

53 termes. Dans chaque brief, les mots soulignés en pointillés affichent leur définition au survol ou au toucher.

Agent
IA qui enchaîne seule plusieurs actions (chercher, lire, écrire, exécuter) pour atteindre un objectif.
API
Accès direct au modèle depuis un logiciel ou un script, facturé à l'usage (au token).
ARC-AGI
Énigmes visuelles inédites qui mesurent la capacité à raisonner sur un problème jamais vu.
Bac à sable (sandbox)
Environnement isolé où l'IA exécute du code sans pouvoir toucher au reste du système.
Batch
Traitement en lot, non urgent (résultat sous 24 h), facturé environ moitié prix.
Benchmark
Test standardisé pour comparer les modèles. Chaque éditeur choisit les siens : un score ne se compare qu'au même test.
Cache
Remise quand on renvoie un texte déjà lu par le modèle (instructions, documents) : ce texte est facturé bien moins cher.
Charte IA Lynxter
Nos règles internes d'usage de l'IA : quelles données, dans quels outils.
Claude Code
Assistant d'Anthropic qui travaille dans un terminal ou un éditeur : code, fichiers, automatisations.
CLI
Outil qui s'utilise en ligne de commande, dans un terminal.
Codex
L'assistant de programmation d'OpenAI, concurrent de Claude Code.
Computer use
L'IA prend la main sur un ordinateur (souris, clavier, écran) pour accomplir une tâche.
Cowork
Application de bureau d'Anthropic où Claude travaille sur des dossiers et des outils connectés.
Cursor
Éditeur de code avec IA intégrée, concurrent de Claude Code.
CursorBench
Test de programmation publié par l'éditeur Cursor, sur des tâches tirées de son logiciel.
DeepSWE
Test de programmation sur des tâches de développement longues, cité par Google pour Gemini.
Dépréciation / retrait
Un modèle déprécié marche encore mais sa date de fin est annoncée. Après le retrait, les appels échouent.
Disponibilité générale (GA)
Version finale ouverte à tous, par opposition à une préversion.
Fenêtre de contexte
Quantité de texte que le modèle garde en tête d'un coup. 1 million de tokens ≈ 1 500 pages.
Fine-tuning
Ré-entraîner un modèle sur ses propres données pour le spécialiser.
GDPval
Test sur des tâches de travail réelles de nombreux métiers (rapports, tableaux), comparées au travail d'experts. Score en points de classement.
GPQA Diamond
Questions de sciences de niveau doctorat, conçues pour ne pas se trouver par une simple recherche.
Hallucination
Réponse fausse donnée avec assurance : fait, chiffre ou source inventés.
Humanity's Last Exam
Questions d'experts très difficiles, dans des dizaines de disciplines.
Infrastructure locale
Serveurs Lynxter (prévus) où faire tourner des modèles ouverts : la seule voie prévue pour les données sensibles.
Latence
Délai avant que la réponse commence à s'afficher.
LLM
Grand modèle de langage : le moteur derrière Claude, ChatGPT, Gemini, Mistral…
MCP
Standard ouvert pour brancher une IA sur un outil ou une base de données (un « connecteur »).
Mixture of Experts (MoE)
Architecture où seule une partie du modèle travaille à chaque mot : plus rapide et moins cher à faire tourner.
Mode raisonnement
Le modèle « réfléchit » avant de répondre : meilleur sur les problèmes difficiles, plus lent et plus cher.
Modèle frontière
Les modèles les plus puissants du moment, chez les grands éditeurs.
Modèle ouvert (open weights)
Modèle téléchargeable : on peut le faire tourner sur ses propres serveurs, sans envoyer de données à l'éditeur.
Multimodal
Capable de traiter du texte et aussi des images, voire du son ou de la vidéo.
Niveau d'effort
Réglage qui dit au modèle combien réfléchir : bas = rapide et économique, haut = plus soigné.
OSWorld
Test où l'IA pilote un vrai ordinateur (clics, fenêtres, logiciels) pour réaliser une tâche de bureau.
Paramètres (taille d'un modèle)
Taille d'un modèle, en milliards (« 30B »). Plus il y en a, plus il faut de matériel pour le faire tourner.
Plugin / mod
Extension qui ajoute des compétences ou change le comportement d'un outil.
Préversion (preview, bêta)
Fonction encore en test : elle peut changer ou disparaître. À éviter pour un usage critique.
Prix « $2/$10 »
Prix pour un million de tokens (≈ 750 000 mots) : le 1er chiffre pour ce que le modèle lit, le 2e pour ce qu'il écrit.
Pull request (PR)
Proposition de modification de code soumise à relecture avant d'être intégrée.
RAG
L'IA va chercher les bons passages dans une base documentaire avant de répondre.
Red team
Équipe qui attaque un système pour en trouver les failles avant de vrais attaquants.
Règle d'interdiction (deny)
Réglage qui empêche Claude Code de lire certains fichiers ou de lancer certaines commandes.
Revue de code automatique
L'IA relit une modification de code avant son intégration et signale bugs et risques.
Routine
Tâche Claude planifiée qui tourne seule dans le cloud, sans PC allumé (ce brief en est une).
SDK
Bibliothèque de code fournie par l'éditeur pour appeler son API depuis un programme.
Skills
Fiches d'instructions qu'un agent charge à la demande pour une tâche précise.
Sortie maximale
Longueur maximale d'une seule réponse du modèle.
SWE-bench Verified
Test de programmation : corriger de vrais bugs de projets open source. Saturé en 2026, les éditeurs ne le publient plus.
Terminal-Bench
Test où l'IA accomplit seule des tâches techniques complètes en ligne de commande : installer, configurer, déboguer.
Token
Morceau de mot (environ ¾ d'un mot). C'est l'unité que les IA lisent, écrivent et facturent.
Tokens par seconde
Vitesse d'écriture du modèle. 300 tokens/s ≈ une demi-page par seconde.
Zéro rétention (ZDR)
Option où l'éditeur ne conserve pas les données envoyées au modèle.
